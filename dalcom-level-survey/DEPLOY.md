# 배포 안내서

링크 하나로 학부모에게 설문을 보내고, 응답을 구글 스프레드시트에 모으는 방법입니다.
순서대로 따라 하면 됩니다. 전부 무료이고, 처음 한 번만 30분 정도 걸립니다.

- **1단계** 구글 스프레드시트 만들기
- **2단계** 수집 스크립트 붙여넣고 주소 받기
- **3단계** GitHub에 프로젝트 올리기
- **4단계** Vercel에 연결하고 배포하기
- **5단계** 잘 되는지 확인하기

---

## 1단계 · 구글 스프레드시트 만들기

1. [sheets.new](https://sheets.new) 에 접속하면 빈 스프레드시트가 열립니다.
2. 왼쪽 위 제목을 **`달콤 유아 단계 설문 응답`** 처럼 알아보기 쉽게 바꿔주세요.
3. 이 창을 닫지 말고 그대로 두세요. 2단계에서 이어서 씁니다.

시트 안에 표를 미리 만들 필요는 없습니다. 첫 응답이 들어오면 자동으로 만들어집니다.

---

## 2단계 · 수집 스크립트 붙여넣고 주소 받기

1. 스프레드시트 상단 메뉴에서 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 새 탭이 열리면서 `function myFunction() { }` 같은 코드가 보입니다.
   **전부 지우고**, 이 프로젝트의 `google-apps-script/Code.gs` 내용을 통째로 붙여넣습니다.
3. 왼쪽 위 저장 아이콘(💾)을 누릅니다.
4. 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
5. 왼쪽의 톱니바퀴(⚙️) → **웹 앱** 을 선택합니다.
6. 아래처럼 설정합니다. **여기가 제일 중요합니다.**

   | 항목 | 선택할 값 |
   | --- | --- |
   | 설명 | 달콤 설문 수집기 (아무거나 괜찮습니다) |
   | 다음 사용자로 실행 | **나** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |

   "액세스 권한이 있는 사용자"를 **모든 사용자**로 하지 않으면 응답이 저장되지 않습니다.

7. **배포** 를 누릅니다. 권한을 묻는 창이 뜨면 승인해 주세요.
   - "이 앱은 확인되지 않았습니다" 경고가 나오면
     **고급 → (프로젝트 이름)(으)로 이동** 을 눌러 계속 진행합니다.
     본인이 만든 스크립트라 안전합니다.
8. 마지막에 나오는 **웹 앱 URL** 을 복사해 둡니다.
   `https://script.google.com/macros/s/AKfycb.../exec` 형태입니다.
   4단계에서 씁니다.

> 나중에 `Code.gs` 를 고치면 **배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포**
> 를 해야 반영됩니다. 이때 주소는 그대로 유지됩니다.

## 3단계 · GitHub에 프로젝트 올리기

`dalcom-level-survey` 폴더를 통째로 GitHub 저장소에 올립니다.

**터미널이 익숙하시면**

```bash
cd dalcom-level-survey
git init
git add .
git commit -m "달콤 유아 단계 추천 설문"
git branch -M main
git remote add origin https://github.com/<계정>/<저장소이름>.git
git push -u origin main
```

**터미널이 부담스러우면** [GitHub Desktop](https://desktop.github.com) 을 설치한 뒤
`File → Add Local Repository` 로 이 폴더를 고르고, `Publish repository` 를 누르면 됩니다.

> `node_modules` 와 `.next` 폴더는 `.gitignore` 에 들어 있어 자동으로 빠집니다.
> 용량이 크고 올릴 필요가 없는 폴더입니다.

## 4단계 · Vercel에 연결하고 배포하기

1. [vercel.com](https://vercel.com) 에 GitHub 계정으로 로그인합니다.
2. **Add New → Project** 를 누르고, 방금 올린 저장소를 고른 뒤 **Import** 합니다.
3. 설정 화면에서 Framework Preset이 **Next.js** 로 잡혀 있는지 확인합니다. (자동으로 잡힙니다)
4. **Environment Variables** 를 펼치고 아래를 입력합니다.

   | Name | Value |
   | --- | --- |
   | `SHEET_WEBHOOK_URL` | 2단계에서 복사한 웹 앱 URL |

5. **Deploy** 를 누릅니다. 1~2분이면 끝납니다.
6. 완료되면 `프로젝트이름.vercel.app` 주소가 나옵니다. 이게 학부모에게 보낼 링크입니다.

**주소를 바꾸고 싶다면** Vercel 프로젝트 → Settings → Domains 에서
`dalcom-survey.vercel.app` 처럼 원하는 이름으로 바꿀 수 있습니다.
달콤교육 도메인이 있다면 `survey.도메인.com` 으로 연결하는 것도 여기서 합니다.

## 5단계 · 잘 되는지 확인하기

1. 배포된 주소를 열어 설문을 처음부터 끝까지 한 번 풀어봅니다.
2. 결과 화면에서 **자세히 보기** 버튼도 눌러봅니다.
3. 1단계에서 만든 스프레드시트를 새로고침합니다.
4. **응답** 시트에 한 줄이 생기고, 답변과 결과, 상세보기 클릭까지 들어와 있으면 성공입니다.

**응답이 안 들어온다면** 대부분 2단계의 "액세스 권한이 있는 사용자"가
**모든 사용자** 로 되어 있지 않아서입니다. 배포 관리에서 다시 확인해 주세요.

## 모이는 데이터

개인정보는 수집하지 않습니다. 이름, 연락처, IP 주소 모두 저장하지 않습니다.

| 항목 | 설명 |
| --- | --- |
| 응답ID | 한 사람의 응답을 묶기 위한 임의의 값 |
| 시작시각 / 완료시각 | 검사를 시작하고 끝낸 시각 |
| 연령 | 4세 / 5세 / 6~7세 |
| 2~11번 답변 | 각 문항의 A 또는 B |
| 총점 / 추천 단계 / 판정 사유 | 계산된 결과 |
| 소요시간 | 시작부터 결과까지 걸린 초 |
| 상세보기 클릭 | 구매 링크를 눌렀으면 O |
| 기기 | 모바일 / 데스크톱 |
| 유입 경로 | 어느 페이지를 거쳐 들어왔는지 |

**시작만 하고 끝내지 않은 사람도 한 줄로 남습니다.** 완료시각이 비어 있는 줄이 그렇습니다.
전체 줄 수와 완료된 줄 수를 비교하면 완료율을 알 수 있습니다.

## 자주 보게 될 숫자

스프레드시트에서 바로 확인할 수 있는 것들입니다.

- **완료율** — 완료시각이 채워진 줄 ÷ 전체 줄
- **단계 분포** — '추천 단계' 열로 피봇 테이블을 만들면 1단계와 2단계 비율이 나옵니다
- **구매 링크 클릭률** — '상세보기 클릭'이 O인 줄 ÷ 완료된 줄
- **연령별 결과 차이** — '연령'과 '추천 단계'로 피봇 테이블

## 수정한 내용을 반영하려면

문항이나 문구를 고친 뒤 GitHub에 올리기만 하면 Vercel이 알아서 다시 배포합니다.
따로 눌러야 할 버튼은 없고, 1~2분 뒤 링크에 반영됩니다.

```bash
git add .
git commit -m "문항 수정"
git push
```
